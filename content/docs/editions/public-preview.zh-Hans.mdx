ObjectOS Cloud 处于**公开预览**阶段。你今天就可以注册，在上面构建和运行
真实的应用。在此期间，有三件事成立：

| | 公开预览期间 |
|---|---|
| **你的数据** | 持久保存。你构建的内容和你存储的记录都会被保留；预览不是一个会被清空的沙箱。 |
| **API** | 可能变化。在正式发布之前，一个端点、一个参数或一个响应形状可能在版本之间发生变化。 |
| **服务水平** | 目前没有 SLA。在正式公布之前，没有可用性承诺，也没有服务赔偿。 |

## 这对你意味着什么 [#what-that-means-for-you]

- **在上面构建。** 你的应用及其数据会延续下去；预览结束时你不需要从头
  再来。
- **锁定你集成的内容。** 如果另一个系统通过 ObjectOS Cloud 的
  [REST API](/docs/reference/rest-api) 或通过 [MCP](/docs/configure/mcp)
  调用它，要预期在 API 变化时重新检查该集成，并关注
  [更新日志](/docs/resources/changelog)。
- **现在就需要 SLA？** 自己运行 ObjectOS。**ObjectOS Enterprise** 在合同下
  提供 SLA 和专属支持；参见[版本对比](/docs/editions/compare)和
  [许可与定价](/docs/editions/license)。

公开预览只是 ObjectOS Cloud 的一个阶段。它与 ObjectOS Community 或
ObjectOS Enterprise 无关，这两者由你自己部署和[升级](/docs/operate/upgrade)。
