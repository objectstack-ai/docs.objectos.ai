ObjectOS 是一个产品、三个版本。**ObjectOS Community** 是你自己运行的开源
运行时。**ObjectOS Cloud** 是为你托管的同一个产品，有 **Free** 和 **Team**
两个套餐。**ObjectOS Enterprise** 是运行在你自己的基础设施上的许可产品：只有一个版本，
始终是私有部署，按合同售卖，按 AI 用户计价。ObjectOS Cloud 上没有 Business
套餐，也没有 Enterprise 套餐。价格与合同见
[许可与定价](/docs/editions/license)；本页讲的是每一个有什么不同。

这份文档中的每一页，标题下方都带有一排版本徽章，标明它适用于哪些版本。
侧边栏用同样的图标标记那些并非适用于所有版本的页面和分组。

## 对照表 [#the-matrix]

| | **Community** | **Cloud Free** | **Cloud Team** | **Enterprise** |
|---|---|---|---|---|
| 交付方式 | 自管理 | 托管 | 托管 | 自管理 |
| 价格 | 免费（Apache-2.0） | 免费 | 24 美元 / AI 席位 / 月，或按年付费 20 美元 / AI 席位 / 月 | 按合同，按 AI 用户计价，最少 25 个：联系销售 |
| 文件存储 | 你自己的（[存储](/docs/configure/storage)） | 每个环境 1 GB | 每个环境 20 GB | 你自己的（[存储](/docs/configure/storage)） |
| 环境 | 你部署多少就有多少 | 每个组织一个 | 每个组织一个 | 你部署多少就有多少 |
| MCP 请求 | 由你的部署设定 | 每分钟 20 次，每天 1,000 次 | 每分钟 120 次，无每日上限 | 由你的部署设定 |
| 自定义域名 | 你自己的主机 | — | — | 你自己的主机 |
| 记录级和字段级安全 | ✓ | ✓ | ✓ | ✓ |
| 审批工作流 | ✓ | — | ✓ | ✓ |
| 定时和相对时间流程 | ✓ | — | ✓ | ✓ |
| UI 内 AI（AI Builder、"问你的数据"） | 仅 MCP —— 自带模型 | 体验版 | ✓ | ✓ |
| AI 治理（动作审计、护栏、权限范围限定） | — | — | — | ✓ |
| 与你的身份提供商单点登录 | ✓（[身份认证](/docs/configure/authentication)） | — | — | ✓ |
| SCIM 2.0 预配 | 开源，默认关闭（`OS_SCIM_ENABLED`） | — | — | 默认开启 |
| 单个部署承载多个组织 | 在框架中开源，Community 镜像不包含（[多组织](/docs/deploy/multi-organization#on-the-community-image)） | — | — | ✓ |
| 高可用（多个副本） | — | — | — | 开发中，尚未提供 |
| 物理隔离运行 | — | — | — | ✓ |
| 支持 | 社区 | 社区 | 标准 | 标准；优先支持和 SLA 支持按合同提供 |

ObjectOS Cloud 上没有 Enterprise 版本：Enterprise 始终是在你所运维的基础设施上的
私有部署。无论部署规模大小，Enterprise 许可证都包含全部 Enterprise 功能。
与你的身份提供商的单点登录和单个部署承载多个组织是开源的，在自管理部署上免费；
Enterprise 许可证为它们加上我们的支持。目前一个部署运行在单个节点上，并支持备份
与恢复；跨多个副本的高可用正在开发中，发布之前不提供。在自管理部署上，Community
和 Enterprise 运行同一个运行时：Community 一列中的一切在 Enterprise 一列中
也都有。

## 每项差异在哪里强制执行 [#where-each-difference-is-enforced]

对照表只列出产品会强制执行的差异。下面这些是本文档已经详细描述过的：

- **许可证决定一个自管理部署是什么。** 没有许可证时，单组织部署以
  Community 的行为运行 —— 开放的 MCP 服务器，自带 AI。有了许可证，
  AI Builder 和"问你的数据"就会在你自己的基础设施上解锁。参见
  [AI 服务](/docs/configure/ai)。
- **在 Enterprise 镜像上，多个组织需要许可证。** 没有许可证的多组织姿态会在
  启动时被拒绝，运行时不会提供服务。多组织运行时本身是开源的；Community
  镜像不包含它。参见[多组织](/docs/deploy/multi-organization)、
  [运行时配置](/docs/configure/runtime)和
  [故障排查](/docs/operate/troubleshooting)。
- **物理隔离运行是一种许可证模式。** 普通许可证会针对控制平面在线校验；
  物理隔离许可证在本地校验，并且部署还必须声明没有控制平面。无法工作的
  组合会在启动时被拒绝。参见[物理隔离部署](/docs/deploy/air-gapped)。
- **在 ObjectOS Cloud 上，套餐按环境强制执行。** 每个组织在每个套餐上
  都有一个环境；存储已满的环境会拒绝附件上传和批量导入，
  但绝不拒绝单条记录的写入、读取或导出（`403 STORAGE_LIMIT_REACHED`，从 80%
  起发出警告）；超过套餐的请求限额后，MCP 端点会返回 `429`。参见
  [环境](/docs/cloud/environments)和
  [存储与限制](/docs/cloud/storage-and-limits)。
- **订阅结束后会回落到 Community。** Enterprise 功能会关闭，系统及其数据
  继续正常工作。在结束后保留某个版本（版本锁定），只有按合同一次性买断的
  永久许可证才有。有三种需要许可证的配置会改为拒绝启动。参见
  [许可](/docs/deploy/licensing#when-a-license-ends)。

## 这一页适用于哪个版本？ [#which-edition-is-this-page-for]

| 徽章 | 含义 |
|---|---|
| Community | 当你自己运行 ObjectOS Community 时成立 |
| Cloud | 在 ObjectOS Cloud 的 Free 和 Team 套餐上成立 |
| Enterprise | 在获得许可的、自管理的 ObjectOS Enterprise 部署上成立 |

部署和运维适用于两个自管理版本，Community 和 Enterprise：在 ObjectOS
Cloud 上，部署由我们为你运行。
