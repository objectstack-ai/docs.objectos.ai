## ひとつの製品、3 つのエディション [#one-product-three-editions]

ObjectOS は **ObjectStack アプリケーションの公式ランタイム環境**で、3 つのエディションがあります。**ObjectOS Community**（オープンソース、セルフホスト、無料）、**ObjectOS Cloud**（私たちが運用）、**ObjectOS Enterprise**（商用ライセンスのもとであなたが運用）です。ObjectStack は、3 つのエディションが実行するプロトコル、SDK、CLI、フレームワークの名前です。

オープンソースの部分には 2 つの名前と 1 つのライセンスがあります。**[ObjectStack フレームワーク](https://github.com/objectstack-ai/objectstack)**（Apache-2.0）はプロトコル、カーネル、SDK、CLI です。**ObjectOS Community** はそこから構築されたオープンソースのランタイムと Console UI です。本番用のランタイムイメージ、MCP サーバー、権限と共有、監査、あらゆるプロトコル機能など、**独自のアプリケーションを構築、実行、セルフホスト**するために必要なものすべてが無料で、開発と本番の間に機能の制限はありません。そのコードは同じ objectstack リポジトリにあります。ObjectOS Cloud と ObjectOS Enterprise は、その仕組みの上に**組み込みの AI** と**公式に運用 / サポートされる**プラットフォームが欲しいときに購入するものです。

## エディション [#editions]

ObjectOS Community は無料です。2 つの商用エディションは、ひとつの課金単位である **AI シート**を共有します。ObjectOS Cloud はセルフサービスで、ObjectOS Enterprise は年間契約で販売します。

| | **Community** | **Free** | **Team** | **Enterprise** |
|---|---|---|---|---|
| エディション | ObjectOS Community | ObjectOS Cloud | ObjectOS Cloud | ObjectOS Enterprise |
| 提供形態 | **セルフマネージド** | クラウド | クラウド | **セルフマネージド**（プライベートデプロイ） |
| 料金 | **無料**（Apache-2.0） | **無料** | **$24** / AI シート / 月、または年払いで $20 / AI シート / 月 | AI ユーザー単位、年額請求、最低 25 ユーザー：[営業にお問い合わせください](mailto:sales@objectos.ai) |
| UI 内の AI（AI Builder +「データに質問する」） | MCP のみ（モデルは持ち込み） | お試し | ✓ | ✓ |
| AI ガバナンス（アクションの監査、ガードレール、権限のスコープ設定） | — | — | — | ✓ |
| 自社のアイデンティティプロバイダーによるシングルサインオン | ✓ | — | — | ✓ |
| ひとつのデプロイ上の複数の組織 | オープンソース、Community イメージには含まれません | — | — | ✓ |
| エアギャップ、デフォルトで有効な SCIM、階層セキュリティ | — | — | — | ✓ |
| 高可用性（複数のレプリカ） | — | — | — | 開発中、まだ提供していません |
| サポート | コミュニティ | コミュニティ | スタンダード | スタンダード。優先と SLA は契約で |

ObjectOS Cloud は **Free** と **Team** で、Business プランも Enterprise プランもありません。Team にはメンバー、レコード、オブジェクトの数の上限がありません。**ObjectOS Enterprise** はひとつのエディションで、常に自社のインフラストラクチャ上のプライベートデプロイです。AI ユーザー単位でライセンスされ、年額で請求され、最低 25 AI ユーザーからで、請求書払いの契約で販売されます。カードでの購入も公開価格もありません。[営業にお問い合わせください](mailto:sales@objectos.ai)。

**無料で**セルフホストしたいですか？それが **ObjectOS Community** です（MCP のみの AI：モデルは持ち込み）。下の [ObjectOS Community](#objectos-community) を参照してください。

**オープンな仕組み、クローズドなインテリジェンス。** データをモデル化しアプリを実行するために必要なものはすべてオープンソースです（ObjectStack フレームワーク上の ObjectOS Community）。Cloud と Enterprise は、その上に*組み込みのインテリジェンス*（製品内の AI Builder と「データに質問する」アシスタント。ガバナンスと監査付き）を重ね、さらに運用のスケールと公式サポートを加えます。

**支払うのは AI シートだけです。** 課金されるシートは **AI シート**だけで、製品内の AI のユーザーごとに 1 つです。閲覧者と AI を使わないアプリユーザーは無料で、ユーザーごとのシート課金はありません（ユーザーあたり $150〜300 の既存製品とは明確に対照的です）。Cloud では、MCP 上で構築する開発者も無料です。Enterprise では、自分の API キーで MCP 経由で接続するエージェントはサービス ID であり、それぞれが 1 AI ユーザーとして数えられます。

## クラウドかセルフマネージドか [#cloud-or-self-managed]

セルフマネージドの ObjectOS は、**ObjectOS Community**（無料）または **ObjectOS Enterprise**（ライセンス制）です。Cloud は Free と Team で、Enterprise は常にセルフマネージドです。

- **Cloud（Free / Team）**：フルホスト型、セルフサービス。料金にはホスティングと AI の利用が含まれます（モデルは私たちが実行します）。環境ごとに上限があります。[AI クレジットと上限](/docs/cloud/ai-credits-and-limits)を参照してください。
- **Enterprise**：自社のインフラストラクチャ上のライセンス制の ObjectOS です。ひとつのエディションで、プライベートデプロイとして、契約で販売されます。
  - **すべての機能が含まれます**。デプロイの規模にかかわらず、UI 内の AI、AI ガバナンス、階層セキュリティ、デフォルトで有効な SCIM、顧客管理の鍵、エアギャップのライセンス、データレジデンシーです。**モデル / キーは持ち込み**です。LLM のコストは自分で支払い、プラットフォームの AI 請求や従量課金はありません。
  - **AI ユーザー単位の料金**で、年額で請求され、最低 25 AI ユーザーからです。ライセンスはノードの数を制限しません。現在、デプロイは 1 つのノードで動作し、バックアップと復元に対応しています。複数のレプリカにまたがる高可用性は開発中で、リリースされるまで提供されません。
  - **契約でのみ購入**でき、請求書払いです。カードでの購入はありません。料金を変えるものは契約で合意します。優先サポートと SLA サポート、エアギャップのデプロイ、複数年の価格固定、永続ライセンスです。
  - **サブスクリプションが終了すると**、デプロイは Community に戻ります。Enterprise の機能はオフになり、システムとデータは動作し続けます。契約で買い切る永続ライセンスだけが、保守料を支払っていた期間にリリースされたバージョンを保持します。

**ノードごとの課金はありません**。

## それぞれが適するとき [#when-you-might-want-each]

| シナリオ | 選ぶもの |
|---|---|
| プラットフォームを**ホストして運用してほしい** | ObjectOS Cloud（Free → Team） |
| **自社のインフラストラクチャ上で製品内の AI**、AI ガバナンス、**エアギャップ**、**SCIM**、SLA、請求書払いが欲しい | **ObjectOS Enterprise**：[営業にお問い合わせください](mailto:sales@objectos.ai) |

| **無料のセルフホスト**で、MCP 経由で AI を持ち込みたい | **ObjectOS Community**（オープンソース） |
| ObjectOS または ObjectStack の名前で **OEM / 再配布**の権利が必要 | 商用契約：[営業にお問い合わせください](mailto:sales@objectos.ai) |

Apache-2.0 であるもの（objectstack リポジトリ内）：ランタイムイメージ、すべての`@objectstack/*` npm パッケージ（ランタイム、プラグイン、サービス、ドライバー、アダプター、CLI、クライアント SDK）、templates リポジトリ、そして Console UI（それが提供する Account アプリを含む）。ドキュメントは CC-BY-4.0 です。

## サードパーティのコンポーネント [#third-party-components]

ObjectOS は ObjectStack フレームワークと、いくつかの上流のオープンソースプロジェクト（Node.js、Hono、Zod、Better Auth、AI SDK など）の上に構築されています。それぞれに独自のライセンスが付属し、すべて商用利用と互換性のある Apache-2.0、MIT、BSD 系の寛容なライセンスです。完全な一覧は、各リリースとともに公開される SBOM を参照してください。

## よくある質問 [#faq]

### ObjectOS はオープンソースですか？ [#is-objectos-open-source]

**ObjectOS Community** はオープンソースです。ランタイムと Console は Apache-2.0 で無料、そのもととなる ObjectStack フレームワークと並んで [objectstack リポジトリ](https://github.com/objectstack-ai/objectstack)でオープンに開発されています。**ObjectOS Cloud**と **ObjectOS Enterprise** は商用エディションで、同じ仕組みの上に組み込みの AI、ホスティングと運用、サポートを加えたものです。自社のアイデンティティプロバイダーによるシングルサインオンは、オープンな仕組みの一部で無料です。

### 顧客に販売するクローズドソースの SaaS で ObjectStack を使えますか？ [#can-i-use-objectstack-in-a-closed-source-saas-i-sell-to-my-customers]

はい。Apache-2.0 にはコピーレフトもロイヤリティもありません。コードを共有する必要はなく、製品が利益を上げても支払うものはありません。

### 支払いなしで ObjectOS をセルフホストできますか？ [#can-i-self-host-objectos-without-paying]

はい。それが **ObjectOS Community** です。同じオープンな仕組みをセルフホストし、AI は MCP のみ（モデルは持ち込み）です。*ライセンス制*のセルフマネージドエディションは ObjectOS Enterprise で、製品内の AI、AI ガバナンス、商用サポートを追加します。

### 更新しないとソフトウェアは動かなくなりますか？ [#does-the-software-stop-working-if-i-dont-renew]

使えなくなることは決してありません。サブスクリプションが終了すると、デプロイは Community に戻ります。Enterprise の機能はオフになり、システムとデータは動作し続けます。終了後もあるバージョンを使い続けること（バージョンロック）は、契約で買い切る**永続ライセンス**にだけ付きます。保守料を支払っていた期間にリリースされたバージョンを保持します。存在するためにライセンスを必要とする 3 つの構成は、代わりに起動を拒否します。[ライセンス](/docs/deploy/licensing#when-a-license-ends)を参照してください。

### ObjectOS は外部に通信しますか？ [#does-objectos-phone-home]

ObjectOS Enterprise はライセンスをオンラインで検証します。エアギャップの Enterprise ライセンスはオフラインで検証します。ObjectOS Community にはテレメトリも、ライセンスチェックも、アップデートの確認通信もありません。

### セルフマネージドのデプロイに商用サポートを購入できますか？ [#can-i-buy-commercial-support-for-a-self-managed-deployment]

優先と SLA のオプションを含む商用サポートは、ObjectOS Enterprise のライセンスに付きます。[営業にお問い合わせください](mailto:sales@objectos.ai)。ObjectOS Community はコミュニティがサポートします。[サポート](/docs/resources/support)を参照してください。

### ObjectOS Community とフレームワークはずっと無料ですか？ [#will-objectos-community-and-the-framework-always-be-free]

はい。Apache-2.0 の許諾は取り消し不能であり、すでにリリースされたものはすべてリリース時のライセンスのままです。
