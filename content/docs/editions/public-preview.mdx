ObjectOS Cloud is in **Public Preview**. You can sign up, build and run real
apps on it today. Three things are true while it is:

| | During Public Preview |
|---|---|
| **Your data** | Durable. What you build and the records you store are kept; the preview is not a sandbox that gets wiped. |
| **APIs** | May change. An endpoint, a parameter or a response shape can change between releases before general availability. |
| **Service level** | No SLA yet. There is no uptime commitment or service credit until one is published. |

## What that means for you

- **Build on it.** Your apps and their data carry forward; you do not start
  over when the preview ends.
- **Pin what you integrate.** If another system calls ObjectOS Cloud over its
  [REST API](/docs/reference/rest-api) or through
  [MCP](/docs/configure/mcp), expect to revisit that integration when an API
  changes, and watch the [Changelog](/docs/resources/changelog).
- **Need an SLA now?** Run ObjectOS yourself. **ObjectOS Enterprise** comes
  with SLA and dedicated support under contract; see
  [Compare Editions](/docs/editions/compare) and
  [License & Pricing](/docs/editions/license).

Public Preview is a stage of ObjectOS Cloud only. It says nothing about
ObjectOS Community or ObjectOS Enterprise, which you deploy and
[upgrade](/docs/operate/upgrade) yourself.
