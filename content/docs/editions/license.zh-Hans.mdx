## 一个产品，三个版本 [#one-product-three-editions]

ObjectOS 是 **ObjectStack 应用的官方运行时环境**，有三个版本：
**ObjectOS Community**（开源、自托管、免费）、**ObjectOS Cloud**（由我们
运维）和 **ObjectOS Enterprise**（由你在商业许可下运维）。ObjectStack 是这
三个版本所运行的协议、SDK、CLI 和框架的名称。

开源这部分有两个名字、一个许可证。
**[ObjectStack 框架](https://github.com/objectstack-ai/objectstack)**
（Apache-2.0）是协议、内核、SDK 和 CLI；**ObjectOS Community** 是由它构建
的开源运行时和 Console UI —— 生产级运行时镜像、MCP 服务器、权限与共享、
审计、每一项协议能力 —— **构建、运行和自托管你自己的应用**所需的一切，
免费，开发与生产之间没有功能关卡。它的代码位于同一个 objectstack 仓库中。
当你想在这套机制之上获得**嵌入式 AI** 和一个**官方运维 / 官方支持**的平台
时，你购买的就是 ObjectOS Cloud 和 ObjectOS Enterprise。

## 版本 [#editions]

ObjectOS Community 免费。两个商业版本使用同一个计价单位，即 **AI 席位**：
ObjectOS Cloud 自助销售，ObjectOS Enterprise 按年度合同销售。

| | **Community** | **Free** | **Team** | **Enterprise** |
|---|---|---|---|---|
| 版本 | ObjectOS Community | ObjectOS Cloud | ObjectOS Cloud | ObjectOS Enterprise |
| 交付方式 | **自管理** | 云 | 云 | **自管理**（私有部署） |
| 价格 | **免费**（Apache-2.0） | **免费** | **24 美元** / AI 席位 / 月，或按年付费 20 美元 / AI 席位 / 月 | 按 AI 用户计价，按年计费，最少 25 个：[联系销售](mailto:sales@objectos.ai) |
| UI 内 AI（AI Builder + "问你的数据"） | 仅 MCP（自带模型） | 体验版 | ✓ | ✓ |
| AI 治理（动作审计、护栏、权限范围限定） | — | — | — | ✓ |
| 与你的身份提供商单点登录 | ✓ | — | — | ✓ |
| 单个部署承载多个组织 | 开源，Community 镜像不包含 | — | — | ✓ |
| 物理隔离、默认开启的 SCIM、层级安全 | — | — | — | ✓ |
| 高可用（多个副本） | — | — | — | 开发中，尚未提供 |
| 支持 | 社区 | 社区 | 标准 | 标准；优先支持和 SLA 按合同提供 |

ObjectOS Cloud 就是 **Free** 和 **Team**；没有 Business 套餐，也没有
Enterprise 套餐。Team 不限制成员、记录或对象的数量。
**ObjectOS Enterprise** 只有一个版本，始终是在你自己的基础设施上的私有部署。
它按 AI 用户授权，按年计费，最少 25 个 AI 用户，按合同销售并以发票付款。
没有刷卡结账，也没有公开价格：
[联系销售](mailto:sales@objectos.ai)。

想**免费**自托管？那就是 **ObjectOS Community**（仅 MCP 的 AI：自带模型）。
参见下文的 [ObjectOS Community](#objectos-community)。

**开放的机制，封闭的智能。** 建模数据和运行应用所需的一切都是开源的
（ObjectOS Community，基于 ObjectStack 框架）。Cloud 和 Enterprise 在其上
叠加了*嵌入式智能* —— 产品内的 AI Builder 和"问你的数据"助手，经过治理
和审计 —— 再加上运营规模和官方支持。

**你只为 AI 席位付费。** 唯一计费的席位是 **AI 席位**，产品内 AI 的每个用户
一个；只读用户和不使用 AI 的应用用户都免费，没有按用户收取的席位税（与那些
每用户 150–300 美元的老牌厂商形成鲜明对比）。在 Cloud 上，通过 MCP 构建的
开发者也免费。在 Enterprise 上，用自己的 API Key 通过 MCP 连接的 Agent 是
一个服务身份，每个都计为一个 AI 用户。

## 云还是自管理 [#cloud-or-self-managed]

自管理的 ObjectOS 是 **ObjectOS Community**（免费）或 **ObjectOS
Enterprise**（需许可）。云是 Free 和 Team；Enterprise 始终是自管理的。

- **云（Free / Team）** —— 完全托管，自助开通。价格包含托管和 AI 用量
  （模型由我们运行），每个环境有各自的限制：
  参见 [AI 点数与限制](/docs/cloud/ai-credits-and-limits)。
- **Enterprise** —— 在你自己的基础设施上运行的需许可的 ObjectOS：只有一个
  版本，私有部署，按合同销售。
  - **包含全部功能**，无论部署规模大小：UI 内 AI、AI 治理、层级安全、默认
    开启的 SCIM、客户自管密钥、物理隔离许可和数据驻留。你**自带模型 /
    密钥**：你自己承担 LLM 成本，没有平台 AI 账单或计量。
  - **按 AI 用户计价**，按年计费，最少 25 个 AI 用户。许可证不限制节点数量。
    目前一个部署运行在单个节点上，并支持备份与恢复；跨多个副本的高可用正在
    开发中，发布之前不提供。
  - **只能按合同购买**，以发票付款；没有刷卡结账。影响价格的因素在合同中
    约定：优先支持和 SLA 支持、物理隔离部署、多年锁价，以及永久许可证。
  - **订阅结束时**，部署会回落到 Community：Enterprise 功能关闭，系统和你的
    数据继续正常工作。只有按合同一次性买断的永久许可证，才会保留其维护费
    已付期间发布的版本。

**不按节点收费**。

## 什么时候选哪个 [#when-you-might-want-each]

| 场景 | 选择 |
|---|---|
| 你希望平台**由别人托管和运维** | ObjectOS Cloud（Free → Team） |
| 你想要**在你自己的基础设施上使用产品内 AI**、AI 治理、**物理隔离**、**SCIM**、SLA 或发票付款 | **ObjectOS Enterprise** —— [联系销售](mailto:sales@objectos.ai) |
| 你需要**与你自己的身份提供商的 SSO**，或在一个部署上承载**多个组织**，并附带商业支持 | **ObjectOS Enterprise**。两者都是开源的，所以你也可以不用许可证运行它们 |
| 你想要**免费自托管**，并通过 MCP 自带 AI | **ObjectOS Community**（开源） |
| 你需要以 ObjectOS 或 ObjectStack 名义进行 **OEM / 再分发**的权利 | 商业协议 —— [联系销售](mailto:sales@objectos.ai) |

**ObjectOS Community** —— 运行时镜像和 Console UI —— 以及构建它的
**ObjectStack 框架**，均采用
[Apache License, Version 2.0](https://www.apache.org/licenses/LICENSE-2.0)
授权：没有 copyleft，有明确的专利授权，永久免费 —— 没有席位，没有用量
档位，没有许可证服务器，没有密钥，没有遥测。在你的笔记本、你的服务器、
你客户的服务器或一个 1000 个 Pod 的集群上运行它；许可证在任何情况下都
一样。你在那里的 AI 路径是开放的 **MCP 服务器**：把你自己的 Claude Code
（或任何 MCP 客户端）指向你的部署，它就能用你自己的模型查询和操作你的
数据。

Apache-2.0 授权的内容（位于 objectstack 仓库中）：运行时镜像、所有
`@objectstack/*` npm 包（运行时、插件、服务、驱动、适配器、CLI、客户端
SDK）、templates 仓库，以及 Console UI，包括它提供的 Account 应用。
文档采用 CC-BY-4.0。

全文：[LICENSE](https://github.com/objectstack-ai/objectstack/blob/main/LICENSE)

## 第三方组件 [#third-party-components]

ObjectOS 构建在 ObjectStack 框架和若干上游开源项目（Node.js、Hono、Zod、
Better Auth、AI SDK ……）之上。每个组件都带有自己的许可证 —— 全部是
Apache-2.0、MIT 或 BSD 风格的宽松许可证，兼容商业使用。完整清单见每个
版本随附发布的 SBOM。

## 常见问题 [#faq]

### ObjectOS 是开源的吗？ [#is-objectos-open-source]

**ObjectOS Community** 是：运行时和 Console 采用 Apache-2.0，免费，并在
[objectstack 仓库](https://github.com/objectstack-ai/objectstack)中公开
开发，与构建它们的 ObjectStack 框架放在一起。**ObjectOS Cloud** 和
**ObjectOS Enterprise** 是商业版本 —— 在同一套机制之上提供嵌入式 AI、
托管与运维，以及支持。与你的身份提供商的单点登录属于开放机制的一部分，
免费。

### 我能在卖给客户的闭源 SaaS 中使用 ObjectStack 吗？ [#can-i-use-objectstack-in-a-closed-source-saas-i-sell-to-my-customers]

可以。Apache-2.0 没有 copyleft，也没有版税 —— 你不需要公开你的代码，
即使你的产品赚了钱，你也不欠任何费用。

### 我能不付费自托管 ObjectOS 吗？ [#can-i-self-host-objectos-without-paying]

可以 —— 那就是 **ObjectOS Community**：同样开放的机制，自托管，AI 仅通过
MCP（自带模型）。*需许可*的自管理版本是 ObjectOS Enterprise，它增加了
产品内 AI、AI 治理和商业支持。

### 如果我不续约，软件会停止工作吗？ [#does-the-software-stop-working-if-i-dont-renew]

它永远不会变砖。订阅结束时，部署会回落到 Community：Enterprise 功能关闭，
系统和你的数据继续正常工作。在结束后保留某个版本（版本锁定），只有按合同
一次性买断的**永久许可证**才有：它保留其维护费已付期间发布的版本。有三种
必须有许可证才能存在的配置会改为拒绝启动；参见
[许可](/docs/deploy/licensing#when-a-license-ends)。

### ObjectOS 会"回传数据"吗？ [#does-objectos-phone-home]

ObjectOS Enterprise 会在线校验许可证；物理隔离的 Enterprise 许可证离线
校验。ObjectOS Community 没有遥测，没有许可证检查，也没有更新探测。

### 我能为自管理部署购买商业支持吗？ [#can-i-buy-commercial-support-for-a-self-managed-deployment]

商业支持（包括优先和 SLA 选项）随 ObjectOS Enterprise 许可证提供：
[联系销售](mailto:sales@objectos.ai)。ObjectOS Community 由社区提供支持；
参见[支持](/docs/resources/support)。

### ObjectOS Community 和框架会一直免费吗？ [#will-objectos-community-and-the-framework-always-be-free]

会。Apache-2.0 的授予不可撤销，所有已经发布的内容都会保持发布时的许可。
