ObjectOS は 3 つのエディションを持つひとつの製品です。**ObjectOS Community** は自分で実行するオープンソースのランタイムです。**ObjectOS Cloud** は同じ製品をあなたのためにホストしたもので、**Free** と **Team** のプランがあります。**ObjectOS Enterprise** は自社のインフラストラクチャ上で動作するライセンス制の製品です。エディションはひとつだけで、常にプライベートデプロイであり、契約で販売され、AI ユーザー単位で価格が決まります。ObjectOS Cloud に Business プランも Enterprise プランもありません。料金と契約は[ライセンスと料金](/docs/editions/license)にあります。このページは、それぞれが何を違う形で行うかを説明します。

このドキュメントのすべてのページは、タイトルの下にエディションバッジの行を持ち、適用されるエディションを示します。サイドバーは、すべてのエディション向けではないページとグループに同じアイコンで印を付けます。

## 比較表 [#the-matrix]

| | **Community** | **Cloud Free** | **Cloud Team** | **Enterprise** |
|---|---|---|---|---|
| 提供形態 | セルフマネージド | ホスト型 | ホスト型 | セルフマネージド |
| 料金 | 無料（Apache-2.0） | 無料 | $24 / AI シート / 月、または年払いで $20 / AI シート / 月 | 契約による。AI ユーザー単位、最低 25 ユーザー。営業にお問い合わせください |
| ファイルストレージ | 自前（[ストレージ](/docs/configure/storage)） | 環境ごとに 1 GB | 環境ごとに 20 GB | 自前（[ストレージ](/docs/configure/storage)） |
| 環境 | デプロイした数だけ | 組織ごとに 1 つ | 組織ごとに 1 つ | デプロイした数だけ |
| MCP リクエスト | デプロイで設定 | 20 / 分、1,000 / 日 | 120 / 分、1 日の上限なし | デプロイで設定 |
| カスタムドメイン | 自前のホスト | — | — | 自前のホスト |
| レコードレベルおよびフィールドレベルのセキュリティ | ✓ | ✓ | ✓ | ✓ |
| 承認ワークフロー | ✓ | — | ✓ | ✓ |
| スケジュールと相対時間のフロー | ✓ | — | ✓ | ✓ |
| UI 内の AI（AI Builder、「データに質問する」） | MCP のみ：モデルは持ち込み | お試し | ✓ | ✓ |
| AI ガバナンス（アクションの監査、ガードレール、権限のスコープ設定） | — | — | — | ✓ |
| 自社の ID プロバイダーによるシングルサインオン | ✓（[認証](/docs/configure/authentication)） | — | — | ✓ |
| SCIM 2.0 プロビジョニング | オープン、デフォルトでオフ（`OS_SCIM_ENABLED`） | — | — | デフォルトでオン |
| ひとつのデプロイ上の複数の組織 | フレームワークではオープンソース、Community イメージには含まれません（[マルチ組織](/docs/deploy/multi-organization#on-the-community-image)） | — | — | ✓ |
| 高可用性（複数のレプリカ） | — | — | — | 開発中、まだ提供していません |
| エアギャップ運用 | — | — | — | ✓ |
| サポート | コミュニティ | コミュニティ | スタンダード | スタンダード。優先サポートと SLA サポートは契約で |

ObjectOS Cloud に Enterprise エディションはありません。Enterprise は常に、あなたが運用するインフラストラクチャ上のプライベートデプロイです。Enterprise ライセンスには、デプロイの規模にかかわらず、すべての Enterprise 機能が含まれます。自社のアイデンティティプロバイダーによるシングルサインオンと、ひとつのデプロイ上の複数の組織はオープンソースで、セルフマネージドのデプロイでは無料です。Enterprise ライセンスは、それらに私たちのサポートを加えます。現在、デプロイは 1 つのノードで動作し、バックアップと復元に対応しています。複数のレプリカにまたがる高可用性は開発中で、リリースされるまで提供されません。セルフマネージドのデプロイでは、Community と Enterprise は同じランタイムを実行します。Community 列にあるものはすべて Enterprise 列にもあります。

## 各違いがどこで強制されるか [#where-each-difference-is-enforced]

比較表には、製品が強制する違いだけを載せています。以下は、このドキュメントですでに詳しく説明しているものです。

- **ライセンスが、セルフマネージドのデプロイが何であるかを決めます。** ライセンスがない場合、単一組織のデプロイは Community の動作で実行されます。オープンな MCP サーバーで、AI は持ち込みです。ライセンスがある場合、AI Builder と「データに質問する」が自社のインフラストラクチャ上で利用可能になります。[AI サービス](/docs/configure/ai)を参照してください。
- **Enterprise イメージでは、複数の組織にライセンスが必要です。** ライセンスなしのマルチ組織の体制は起動時に拒否され、ランタイムはトラフィックを処理しません。マルチ組織のランタイム自体はオープンソースですが、Community イメージには含まれません。[マルチ組織](/docs/deploy/multi-organization)、[ランタイム設定](/docs/configure/runtime)、[トラブルシューティング](/docs/operate/troubleshooting)を参照してください。
- **エアギャップ運用はライセンスモードです。** 通常のライセンスはコントロールプレーンに対してオンラインで検証されます。エアギャップライセンスはローカルで検証され、デプロイはコントロールプレーンがないことも宣言しなければなりません。機能し得ない組み合わせは起動時に拒否されます。[エアギャップデプロイ](/docs/deploy/air-gapped)を参照してください。
- **ObjectOS Cloud では、プランは環境ごとに強制されます。** 組織はどのプランでも 1 つの環境を持ちます。容量が満杯の環境は添付ファイルのアップロードと一括インポートを拒否しますが、単一レコードの書き込み、読み取り、エクスポートは決して拒否しません（`403 STORAGE_LIMIT_REACHED`、80% から警告）。MCP エンドポイントはプランのリクエスト上限を超えると `429` を返します。[環境](/docs/cloud/environments)と[ストレージと上限](/docs/cloud/storage-and-limits)を参照してください。
- **サブスクリプションが終了すると Community に戻ります。** Enterprise の機能はオフになり、システムとそのデータは動作し続けます。終了後もあるバージョンを使い続けること（バージョンロック）は、契約で買い切る永続ライセンスにだけ付きます。ライセンスを必要とする 3 つの構成は、代わりに起動を拒否します。[ライセンス](/docs/deploy/licensing#when-a-license-ends)を参照してください。

## このページはどのエディション向けか [#which-edition-is-this-page-for]

| バッジ | 意味 |
|---|---|
| Community | ObjectOS Community を自分で実行する場合に当てはまる |
| Cloud | ObjectOS Cloud の Free および Team プランで当てはまる |
| Enterprise | ライセンスを受けたセルフマネージドの ObjectOS Enterprise デプロイで当てはまる |

デプロイと運用は、2 つのセルフマネージドのエディション、Community と Enterprise 向けです。ObjectOS Cloud では、私たちがデプロイを運用します。
