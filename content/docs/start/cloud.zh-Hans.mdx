**ObjectOS Cloud** 是为你托管和运维的 ObjectOS：你在浏览器中工作，无需
安装或部署任何东西。**Free** 套餐就足够构建你的第一个应用。ObjectOS Cloud
目前处于[公开预览](/docs/editions/public-preview)阶段。

想在你自己的机器上运行？那是
[ObjectOS Community](/docs/start/community)。在你自己的基础设施上、获得
许可证授权？那是 [ObjectOS Enterprise](/docs/start/enterprise)。

## 1. 注册 [#1-sign-up]

从 [www.objectos.ai](https://www.objectos.ai) 开始，创建你的账户。

## 2. 创建你的组织 [#2-create-your-organization]

组织是你的团队共享的工作空间：它的应用、它的数据和它的成员。给它起一个
名称和一个 **slug** —— ObjectOS 用来指代它的简短标识符。

## 3. 创建生产环境 [#3-create-the-production-environment]

组织在一个环境中运行它的应用。创建它的**生产环境**；你的第一个应用就在
那里。在 Free 套餐上，生产环境是唯一的环境 —— 参见
[环境](/docs/cloud/environments)。

## 4. 构建你的第一个应用 [#4-build-your-first-app]

两种方式，你可以都用：

- **向 [AI Builder](/docs/build/ai-builder) 描述它** —— *"我需要跟踪带
  优先级和负责人的支持工单"*。它会把对象、字段和视图作为一个变更提出来，
  由你批准后才会运行。
- **安装一个[模板](/docs/build/templates)**，从一个可用的应用开始。

开发者还有两条路线：在源码中构建并发布一个
[包](/docs/build/packages#two-developer-routes-on-objectos-cloud)，或者让
他们自己的 Agent 通过 [MCP](/docs/configure/mcp#build-with-an-agent) 以草稿形式构建，
再由人来发布。无论哪种方式，结果都是普通的 ObjectStack
元数据：REST API、生成的界面、权限和审计都随之而来。你接下来能添加的所有内容见
[构建](/docs/build)。

## 5. 邀请你的团队 [#5-invite-your-team]

邀请将要使用这个应用的人。只有 **AI 席位**计费：只读用户和不使用产品内
AI 来使用应用的人都是免费的。邀请和角色参见
[组织与成员](/docs/cloud/organization)，环境内的访问参见[用户](/docs/configure/users)，
谁能看到什么参见[权限](/docs/configure/permissions)。
