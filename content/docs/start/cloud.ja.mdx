**ObjectOS Cloud** は、あなたのためにホストされ運用される ObjectOS です。作業はブラウザで行い、インストールやデプロイするものは何もありません。**Free** プランで最初のアプリを構築するには十分です。ObjectOS Cloud は[パブリックプレビュー](/docs/editions/public-preview)段階です。

自分のマシン上で使いたいですか？それは [ObjectOS Community](/docs/start/community) です。自社のインフラストラクチャ上で、ライセンスを受けて使いたいなら、[ObjectOS Enterprise](/docs/start/enterprise) です。

## 1. サインアップする [#1-sign-up]

[ObjectOS Cloud のサインアップページ](https://cloud.objectos.ai/_console/register)でアカウントを作成します。すでにアカウントをお持ちの場合は、[サインイン](https://cloud.objectos.ai/_console/login)してください。

## 2. 組織を作成する [#2-create-your-organization]

組織は、チームが共有するワークスペースです。そのアプリ、そのデータ、そのメンバーです。名前と **slug**（ObjectOS が組織を指すのに使う短い識別子）を付けます。

## 3. 本番環境を作成する [#3-create-the-production-environment]

組織はアプリを環境の中で実行します。組織の**本番環境**を作成してください。最初のアプリはそこに置かれます。Free プランでは、本番が唯一の環境です。[環境](/docs/cloud/environments)を参照してください。

## 4. 最初のアプリを構築する [#4-build-your-first-app]

方法は 2 つあり、両方を使えます。

- **[AI Builder](/docs/build/ai-builder) に説明する**：*「サポートチケットを優先度と担当者付きで管理したい」*。AI Builder はオブジェクト、フィールド、ビューを、実行前にあなたが承認する変更として提案します。
- **[テンプレート](/docs/build/templates)をインストールして**、動作するアプリから始めます。

開発者にはさらに 2 つの道があります。ソースで構築して[パッケージ](/docs/build/packages#two-developer-routes-on-objectos-cloud)を公開するか、自分のエージェントに [MCP](/docs/configure/mcp#build-with-an-agent) 経由で、人が公開するドラフトとして構築させます。どちらの場合も、結果は通常の ObjectStack メタデータです。REST API、生成された画面、権限、監査がそれに付いてきます。次に追加できるものすべては[構築](/docs/build)を参照してください。

## 5. チームを招待する [#5-invite-your-team]

アプリを使う人を招待します。課金されるのは **AI シート**だけです。閲覧者と、製品内の AI を使わずにアプリを使う人は無料です。招待とロールについては[組織とメンバー](/docs/cloud/organization)、環境内のアクセスについては[ユーザー](/docs/configure/users)、誰が何を見られるかについては[権限](/docs/configure/permissions)を参照してください。
