**Full specification:** [AI skill reference on objectstack.ai](https://objectstack.ai/docs/ai/skills-reference). This page is the summary: where ObjectOS uses it, and a few examples.

The [`skills`](https://www.npmjs.com/package/skills) CLI (by
[vercel-labs/skills](https://github.com/vercel-labs/skills)) installs
domain-scoped instructions into an AI coding agent. The ObjectStack skills
teach Claude Code, Cursor, Copilot, Codex and the rest to write the metadata
ObjectOS runs — objects, views, flows, permissions, queries, CEL — against the
real schemas, so what the agent writes compiles.

## Where ObjectOS uses it

- **Hand-authoring an app in your IDE.** The in-browser
  [AI Builder](/docs/build/ai-builder) writes metadata for you in ObjectOS;
  the skills give your own coding agent the same vocabulary when you work in a
  repository instead. See [Build → IDE Skills](/docs/build/ai-skills).
- **Keeping an agent current.** The skills live in the
  [objectstack repository](https://github.com/objectstack-ai/objectstack/tree/main/skills)
  beside the schemas they describe, so re-installing after an upgrade brings
  the agent up to date.

## Examples

**Install** the skills into the current project. The CLI detects which agents
the project uses and writes each one's native format (`.claude/skills/`,
`.cursor/rules/`, `AGENTS.md`, …):

```bash
npx skills add objectstack-ai/objectstack/skills
```

**Pin a version** for reproducible CI:

```bash
npx skills add https://github.com/objectstack-ai/objectstack/tree/<commit-sha>/skills
```

**See and manage** what is installed:

```bash
npx skills detect                  # show which agents the CLI will write to
npx skills list                    # list installed skills
npx skills remove <name>           # remove a skill
```

**Commit the output.** Skills are markdown your whole team — CI agents
included — should share, and the paths the CLI writes are ones you would check
in anyway.
