ObjectOS は、プロジェクト、タスク、承認、ダッシュボードなど、チームの業務アプリが置かれる場所です。一度サインインすれば、アクセスできるすべてのアプリをひとつの場所で、ひとつの検索ボックスとともに見られます。

このセクションは**日常的なユーザー**向けです。アプリを構築する人やシステムを管理する人は、代わりに[構築](/docs/build)または[設定](/docs/configure)に進んでください。

## サインイン [#signing-in]

チームから伝えられた URL を開き、**メールアドレスとパスワード**でサインインします。セッションは記憶されるので、アバターメニューからログアウトするまで、そのブラウザではサインインしたままです。

## ホームページ [#the-home-page]

サインインすると、ホームページに移動します。上から順に次のものがあります。

| 領域 | 表示内容 |
|---|---|
| **あいさつ** | 個人宛てのあいさつ（"Good afternoon, Ada"） |
| **あなたのアプリ** | タイルのグリッド。アクセスできるアプリごとに 1 枚です。タイルをクリックするとアプリが開きます。 |
| **Needs your attention**（対応が必要） | 保留中の通知と承認、それぞれが届いてからの経過時間 |
| **Recently Accessed**（最近のアクセス） | 最近開いたオブジェクトとレコード。昨日の作業に戻る最速の方法です |
| **アクティビティフィード** | ワークスペース全体の最近のアクティビティ |

> **ヒント：** **Needs your attention** を朝の受信トレイとして使いましょう。どのアプリを開く前でも、あなたを待っている承認が表示されます。

## アプリを切り替える [#switching-between-apps]

左上の**パンくずリスト**は、常に現在地を示します：*アプリ → オブジェクト → レコード*。最初の部分は**アプリスイッチャー**です。クリックするとアプリの一覧がドロップダウンで表示され、ホームに戻らずにアプリ間を移動できます。

どのインストールにも、チーム向けに構築された業務アプリと並んで、次のものがあります。

| アプリ | 誰が見られるか | 用途 |
|---|---|---|
| **Account** | 全員 | 個人用のスペース：プロフィール、通知の受信トレイ、承認、セキュリティ |
| **Setup** | 管理者のみ | システム管理 |

## アプリのナビゲーションサイドバー [#the-app-navigation-sidebar]

アプリ内では、左のサイドバーがそのアプリのメニューです。フラットな項目と**折りたたみ可能なグループ**（たとえば *Workspace* や *Analytics*）が含まれます。各項目は次の 3 つのいずれかを開きます。

| 項目の種類 | クリックで開くもの |
|---|---|
| オブジェクト（例：*Tasks*） | そのリストビュー。[ビュー](/docs/use/views)を参照してください |
| ページ | アプリ向けに構築されたカスタムページ |
| ダッシュボード | グラフと KPI。[ダッシュボード](/docs/use/dashboards)を参照してください |

アクティブな項目の横には**ピンアイコン**が表示され、よく使う場所をピン留めできます。

## グローバル検索 [#global-search]

`⌘K`（Mac）または `Ctrl-K`（Windows/Linux）を押すか、トップバーの **Search…**（検索）をクリックします。**すべてのオブジェクトにわたるレコード**を検索するダイアログが開きます。タスク名、プロジェクト、顧客の数文字を入力すれば、すぐにそこへ移動できます。

## トップバー [#the-top-bar]

トップバーはすべての画面に表示されます。

| コントロール | 機能 |
|---|---|
| **Search…** | グローバル検索を開く（`⌘K` / `Ctrl-K`） |
| **ベル** | 通知。赤いバッジが未読数を示します。受信トレイ全体は **Account → Inbox → Notifications** にあります。 |
| **?** | ヘルプ |
| **アバター** | アカウントメニュー（下記） |

**アバターメニュー**には名前とメールアドレスが表示され、次の項目があります。

| 項目 | 機能 |
|---|---|
| **Profile**（プロフィール） | Account アプリでプロフィールを開く |
| **Preferences → Theme**（設定 → テーマ） | ライトとダークを切り替える |
| **Preferences → Language**（設定 → 言語） | インターフェースの言語を変更する |
| **Log out**（ログアウト） | セッションを終了する |

> **ヒント：** テーマと言語は**アバターメニュー → Preferences** にあり、プロフィールページにはありません。最初に探しがちな場所です。
