名前、メールアドレス、ステータス、都市名の一部を入力すると、ObjectOS はそれを含むレコードを見つけます。同じ検索が 3 つの場所で動作します。

| 場所 | 検索対象 |
|---|---|
| **グローバル検索**：`⌘K`（Mac） / `Ctrl-K`（Windows/Linux）、またはトップバーの **Search…** | 読み取れるすべてのオブジェクトにわたるレコードと、アプリ自体のメニュー |
| **リスト検索**：ビューのツールバーの虫眼鏡 | 今いるリストのレコード |
| **参照ピッカー**：別のレコードを指すフィールドの **Select…** ボックス | 選択できるレコード |

3 つとも入力した語をサーバーに送り、同じ答えを受け取ります。そのため、ひとつの場所で見つかるレコードは他の場所でも見つかります。

## 一致の仕組み [#how-matching-works]

| 入力 | 見つかるもの |
|---|---|
| 単語の一部：`retail` | 検索対象のフィールドのどこかに `retail` を含むすべてのレコード：*Acme Retail*、または業種が *Retail* の取引先 |
| 大文字小文字は問わない：`Retail`、`RETAIL` | 同じレコード。検索は大文字と小文字を区別しません |
| 複数の語：`retail northwind` | **すべての**語が同じレコードのいずれかのフィールドに一致するレコード |
| 選択肢のラベル：`In Progress` | ステータス（または他の選択フィールド）がその選択肢を持つレコード。保存されている値が異なっていても見つかります |

どのフィールドを検索するかは、アプリを構築した人がオブジェクトごとに設定します。選んでいない場合、検索はレコードの名前またはタイトル、テキストフィールド（メール、電話、URL、長いテキストを含む）、選択フィールドを対象にします。数値、日付、はい/いいえのフィールド、ファイル、他のレコードへのリンクは対象外です。

> **ヒント：** 語を増やすと結果が絞り込まれます。`acme invoice` は Acme の請求書を見つけます。Acme のすべてのレコードとすべての請求書ではありません。

## 見つかるのは読み取れるものだけ [#you-only-find-what-you-can-read]

検索は、リストを開くときと同じく、あなたの権限で実行されます。

- 読み取れないレコードは決して返されず、合計件数にも数えられません。
- アクセス権のないオブジェクトは静かにスキップされます。検索は読み取れるオブジェクトから引き続き答えます。
- あなたから隠されているフィールドは検索されないため、ヒットからその中身が明らかになることはありません。

2 人が同じ語を入力しても、異なる結果になることがあります。それは正しい動作です。それぞれが見ることを許された一致を見ています。

## 常に最新 [#always-up-to-date]

待つべきインデックスはありません。作成したばかりのレコードはすぐに見つかります。名前を変更すると、新しい名前が一致し、古い名前は一致しなくなります。削除したレコードは結果から即座に消えます。

何も一致しない場合は **No results found** と表示されます。エラーではありません。語を減らすか、短くしてみてください。

## 中国語の名前とピンイン [#chinese-names-and-pinyin]

アプリが中国語をサポートしている場合、検索はピンインで入力された中国語の名前にも一致します。完全な綴り（`zhangwei`）または頭文字（`zw`）で **张伟** が見つかり、漢字も入力したとおりに一致し続けます。ピンインはレコードの名前フィールドに適用されます。

ピンイン検索は、アプリの言語に中国語が含まれている場合に有効になります。管理者は `OS_SEARCH_PINYIN_ENABLED` の設定で、デプロイ全体に対してオンまたはオフにできます。

## コマンドパレット [#the-command-palette]

`⌘K` / `Ctrl-K` を押す（または **Search…** をクリックする）とパレットが開きます。検索ボックスとナビゲーターを兼ねています。

| 表示されるもの | 機能 |
|---|---|
| **Recently viewed** | ボックスが空の間に表示されます。最近開いたレコードに 1 クリックで移動できます |
| オブジェクト名の下にグループ化されたレコード | **2 文字以上**入力すると、*Accounts* や *Contacts* などの見出しの下に一致が表示されます。**Enter** で強調表示されたレコードを開きます |
| **Objects**、**Dashboards**、**Pages**、**Reports** | 名前が一致する現在のアプリのメニュー項目。メニューグループ内の項目も含みます |
| **Switch App** | 他のアプリ。現在のアプリには **Current** の印が付きます |
| **Preferences** | **Light Theme**、**Dark Theme**、**System Theme**。即座に適用されます |
| **Open Full Search Page** | 検索ページ（下記）を開きます |

パレットが提示するのは、いずれにせよたどり着けるものだけです。サイドバーで隠されているメニュー項目はここでも隠され、非アクティブなアプリは **Switch App** に表示されません。

> **ヒント：** キーボードから手を離さずに：`⌘K`、入力、矢印キー、**Enter**。もう一度 `⌘K` を押すとパレットが閉じます。

## 検索ページ [#the-search-page]

**Open Full Search Page** は、同じ検索の全画面表示に移動します。一致するアプリのオブジェクト、ダッシュボード、ページ、レポートと、オブジェクトごとにグループ化されたレコードの一致が表示されます。ボックスに入力して絞り込みます。

## リスト内を検索する [#searching-inside-a-list]

ビューのツールバーの虫眼鏡は、今いるリストを絞り込みます。ビューのフィルター、グループ化、ソートと組み合わせて動作します。[ビューを使う](/docs/use/views)を参照してください。*どの*リストかわかっているときに使い、わからないときは `⌘K` を使います。

## アプリビルダー向け [#for-app-builders]

オブジェクトの `searchableFields` は、検索がスキャンするフィールドを設定します。省略すると、上で説明した名前、テキスト、選択フィールドになります。ビューや API 呼び出しはスキャンをそれらのうちの少ないフィールドに絞り込めますが、広げることは決してできません。セット外のフィールドを要求すると、無視されるのではなく拒否されます。計算される `formula` フィールドは保存されないため検索できません。値を保存されるテキストフィールドにコピーして、そちらを検索してください。
