個人的なものはすべて 2 つの場所にあります。右上の**アバターメニュー**（すべての画面で使える手早い設定）と、**Account** アプリ（プロフィール、セキュリティ、受信トレイ）です。ここでの変更が他の人に影響することはありません。これらはあなたのアカウントの、あなたの設定です。

| やりたいこと | 移動先 |
|---|---|
| 名前やアバターを変更する | **Account → Profile** |
| パスワードを変更する | **Account → Profile** → Change Password |
| ライト/ダークモードや言語を切り替える | アバターメニュー → Preferences |
| 他のセッションを確認する、またはサインアウトさせる | **Account → Security** → Active Sessions |
| どのサインインプロバイダーが連携されているか確認する | **Account → Security** → Linked Accounts |
| サインアウトする | アバターメニュー → **Log out** |

## プロフィール [#your-profile]

**Account → Profile** を開きます。アプリスイッチャーの **Account** アプリからでも、アバターメニューの **Profile** からでも開けます。

| 設定 | 変更できるか |
|---|---|
| **アバター** | はい。**Upload** をクリックして画像を選びます。チームメイトは、割り当て、アクティビティフィード、承認など、あなたが表示されるあらゆる場所でそれを目にします。 |
| **名前** | はい。Personal Information カードで編集します。 |
| **メールアドレス** | いいえ。メールアドレスはアカウントを識別するもので、ここでは変更できません。 |
| **ロール** | 読み取り専用。管理者があなたに割り当てたものを表示します。 |

**Save Changes** をクリックして編集を適用します。

Personal Information の下には **Change Password** カードがあります。現在のパスワードと新しいパスワードを入力すれば完了です。他のデバイスは、セッションが終わるまでサインインしたままです。すべて一掃したい場合は、**Active Sessions** からそれらをサインアウトさせてください。

## 設定：テーマと言語 [#preferences-theme-and-language]

右上のアバターをクリックします。名前とメールアドレスと並んで、Preferences があります。

| 設定 | 選択肢 |
|---|---|
| **Theme** | ライトまたはダーク。UI 全体がすぐに切り替わります。 |
| **Language** | UI の表示言語を選びます。 |

どちらもその場で反映されます。保存ボタンも再読み込みもありません。

## セキュリティ [#security]

**Account → Security** を開くと、ときどき確認する価値のある 2 つのものがあります。

| セクション | 用途 |
|---|---|
| **Linked Accounts** | アカウントに連携されたソーシャルまたは会社のサインインプロバイダー（SSO）。何が連携されているかをひと目で確認できます。 |
| **Active Sessions** | 現在あなたとしてサインインしているすべてのデバイスとブラウザ。一覧を確認し、見覚えのないセッションやもう使っていないセッションを**サインアウト**させます。 |

> **ヒント：** 共有のマシンや借りたマシンでサインインしたまま、ログアウトし忘れましたか？そのマシンは必要ありません。どのデバイスからでも **Active Sessions** でそのセッションを失効させられます。

## Account アプリのその他の項目 [#also-in-the-account-app]

| セクション | 用途 |
|---|---|
| **Inbox → My Organizations** | アカウントが所属する組織。 |
| **Inbox → Notifications / Approvals** | 個人の受信トレイ。[通知](/docs/use/notifications)と[承認](/docs/use/approvals)で説明しています。 |
| **Developer → API Keys, OAuth Applications** | 外部ツールを ObjectOS に接続するための認証情報。**ほとんどのユーザーはこのセクションを必要としません**。必要かどうかわからないなら、必要ありません。 |

## ログアウト [#logging-out]

アバターメニューを開き、**Log out** をクリックします。これで使っているデバイスのセッションが終了します。他のデバイスは、**Active Sessions** からサインアウトさせるまで、それぞれのセッションを保持します。
