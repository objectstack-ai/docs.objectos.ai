**ビュー**は、オブジェクトのレコードを見るための保存された方法です。同じタスクを、スプレッドシートのようなグリッド、カンバンボード、カレンダーとして表示できます。自由に切り替えられ、データは何も変わりません。

## ビューのタブ [#view-tabs]

すべてのリストの上部には、オブジェクトのビューがタブとして表示されます。たとえば次のとおりです。

**All Tasks ★ | In Progress | Urgent | Done | … 9 more | +**

| タブの要素 | 意味 |
|---|---|
| **★** | デフォルトのビュー。最初に開くものです |
| 名前付きのタブ（*In Progress*、*Urgent*） | チーム向けに設定された、あらかじめフィルターされたビュー。タブの小さな漏斗のバッジは、組み込みのフィルターがあることを示します。 |
| **… 9 more** | ビューが収まりきらないときのオーバーフローメニュー |
| **+** | 自分の**個人ビュー**を作成します。自分のフィルター、自分の列を、自分専用に保存します |

> **ヒント：** 毎朝同じフィルターを適用し直す代わりに、**+** を一度クリックして個人ビューとして保存しましょう。

## ビューの種類を切り替える [#switching-view-types]

右側のツールバーには、現在のビューの種類（例：**Grid**）が表示されます。クリックすると、同じレコードを見る 6 つの方法を切り替えられます。

| 種類 | 最適な用途 |
|---|---|
| **Grid** | 日常的な表。多数のレコードの一覧、ソート、編集 |
| **Kanban** | 進行中の作業。ボード上でステージを移動するカード |
| **Gallery** | 画像が重要なレコード。製品、デザイン、人 |
| **Calendar** | 日付を持つもの。締め切り、イベント、予約を月または週ごとに |
| **Timeline** | 時間に沿ったレコードの時系列フィード |
| **Gantt** | プロジェクト計画。開始、終了、期間を示すバー |

## ビューのツールバー [#the-view-toolbar]

ビューの種類の切り替えの隣には、次のものがあります。

| コントロール | 機能 |
|---|---|
| **Edit inline** | グリッドでスプレッドシートのようなセル編集を切り替えます。[レコードを操作する](/docs/use/records)を参照してください |
| **Filter** | 選んだ条件に一致するレコードだけを表示します |
| **Group** | 行を見出しの下にまとめます（例：Project や Assignee ごと） |
| **Sort** | レコードを並べ替えます。バッジは有効なソートルールの数を示します |
| 列の設定 | どの列をどの順序で表示するかを選びます |
| 虫眼鏡 | **ビュー内検索**。入力して現在のリストを絞り込みます |

> **ヒント：** ビュー内検索は今いるリストを絞り込みます。`⌘K` / `Ctrl-K` はすべてのオブジェクトにわたってレコードを検索します。*どの*リストかわかっているときは虫眼鏡を、わからないときは `⌘K` を使いましょう。

## グリッドを読む [#reading-a-grid]

グリッドのセルには追加の情報が詰め込まれています。

| 表示されるもの | 意味 |
|---|---|
| 行のチェックボックスと `#` 番号 | 一括アクションのために行を選択し、行数をひと目で数えます |
| 色付きのピル | Status や Priority のような選択フィールドの値。色は値に従います |
| 赤い日付（"Overdue 6d"） | 日付が過ぎています。その日数だけ期限切れです |
| 進捗バー | 完了率のフィールドをバーで表示したもの |
| 行末の `⋮` | 行ごとのアクションメニュー |
| フッターの件数（"10 records"） | 現在のビューに含まれるレコードの数 |

## カンバンボード [#kanban-boards]

**Kanban** に切り替えると、レコードは**列の中のカード**になります。列はオブジェクトの選択フィールドのひとつから作られます。タスクの場合は通常 Status なので、*Backlog*、*To Do*、*In Progress*、*In Review* などになります。

| ボードの要素 | 表示内容 |
|---|---|
| 列ヘッダー | ステージ名と、その列のカードの**件数** |
| カード | レコードのタイトルと主要な詳細。担当者、優先度のピル |
| ツールバー | グリッドと同じ **Filter / Group / Sort** のコントロール |

カンバンは「各ステージにどれだけの作業があるか」にひと目で答えます。列の件数がボトルネックの検出器です。
