ObjectOS のすべては**レコード**です。タスク、プロジェクト、顧客、請求書。このページでは、レコードを開き、そのページを読み、新しいレコードを作成し、多数のレコードを一度に編集する方法を説明します。

## レコードを開く [#opening-a-record]

どのリストでも、**レコードのタイトルはリンク**です。クリックするとレコードページが開きます。戻るには、レコード上部の戻るリンク（たとえば **< All Tasks**）か、左上のパンくずリストを使います。

## レコードページの構成 [#anatomy-of-a-record-page]

レコードページには、上から順に次のものが表示されます。

| 要素 | 内容 |
|---|---|
| **戻るリンク** | 元のリストに戻ります（例：**< All Tasks**） |
| **状態パイプラインバー** | ワークフローを持つオブジェクトのみ。レコードがプロセスのどこにあるかを示す山形のステージ |
| **ハイライト帯** | レコードの主要フィールドの概要（例：Project、Assignee、Priority、Due Date、Progress） |
| **アクションボタン** | このレコードに定義されたアクション。たとえば **Log Time** |
| **フィールドセクション** | 残りのフィールドをカードにまとめたもの（例：Overview、Schedule、Details） |
| **Show N empty fields** | セクションの末尾にあるトグル。ページを短く保つため、空のフィールドはデフォルトで折りたたまれています |

### 状態パイプラインを読む [#reading-the-state-pipeline]

オブジェクトにワークフローがある場合、上部のバーはすべてのステージを山形で表示します。完了したステージにはチェックマークが付き（✓ Backlog → ✓ To Do → ✓ In Progress）、**現在のステージは強調表示**されます。ひと目でレコードの進み具合がわかります。

> **ヒント：** レコードの項目が少なく見える場合は、**Show N empty fields** をクリックしてください。フィールドは存在していて、まだ値がないだけです。

## レコードを作成する [#creating-a-record]

任意のリストの上部にある **+ New** をクリックします。モーダルが開きます（たとえば *"Create Task — Add a new Task to your database"*）。フォームの中には次のものがあります。

| 表示されるもの | 動作 |
|---|---|
| `*` の付いたフィールド | 必須です。入力しないと保存できません |
| **Select…** ピッカー | 別のレコード（Project、User）を指す参照フィールド。入力して検索するか、テーブル閲覧ボタンで完全な一覧から選びます。 |
| ドロップダウン | Status や Priority のような選択フィールド。値をひとつ選びます |
| 日付ピッカー | 日付フィールドをクリックし、カレンダーから日を選びます |

**Create** で完了するか、**Cancel** で破棄します。

## レコードをインラインで編集する [#editing-records-inline]

変更するたびにレコードを開く必要はありません。グリッドビューで、ツールバーの **Edit inline** トグルをオンにすると、セルが編集可能になり、ステータスの修正、タスクの再割り当て、日付の更新をリスト上でスプレッドシートのように直接行えます。

## 行ごとのアクションメニュー [#the-per-row-actions-menu]

グリッドのすべての行の末尾には `⋮` **Actions** メニューがあります。そのレコード 1 件に使えるアクションがまとまっており、先にレコードを開く代わりの手早い方法です。

## 多数のレコードを一度に選択する [#selecting-many-records-at-once]

グリッドの各行は**チェックボックス**で始まります。

1. 対象の行にチェックを入れます（ページ全体ならヘッダーのチェックボックス）。
2. オブジェクトの**一括アクション**（リスト上部の **Reassign…** のようなボタン）が、選択したものすべてに適用されるようになります。

> **ヒント：** 一括アクションはオブジェクトごとに異なります。リストヘッダーの **+ New** と **Import** の隣にあるボタンです。

## リストヘッダーの全体 [#the-list-header-in-full]

すべてのリストの上には次のものがあります。

| ボタン | 機能 |
|---|---|
| **+ New** | レコードを作成する（上で説明したモーダル） |
| **Import** | 1 件ずつ入力する代わりに、ファイルからレコードを取り込む |
| カスタムの一括アクション | **Reassign…** のようなオブジェクト固有の操作を、選択したものに適用する |
| ベルオフのトグル | このオブジェクトの通知をミュートする。[通知](/docs/use/notifications)を参照してください |
