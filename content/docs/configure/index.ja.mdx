このセクションは、ObjectOS デプロイメントの**システム管理者**向けです。ユーザーを迎え入れ、アクセスを付与し、サインイン、メール、ストレージ、連携を設定し、システムを健全に保つ人のことです。あなたは日々、人とその権限を管理します。アプリケーション、オブジェクト、権限セットそのものは、プラットフォームとインストールしたアプリパッケージとともに提供されます。

## Setup と Studio [#setup-and-studio]

**権限は Studio で設計し、Setup で割り当てます。** この一文は、製品全体を貫く区分の正式な表明であり、権限だけについてのルールではありません。Setup は稼働中のデプロイメントを*運用*し、Studio はそのデプロイメントが実行するメタデータを*作成*します。どちらも `/_console/` の同じ UI の中にあり、どちらも独立した画面ではありません。

| | Setup | Studio |
|---|---|---|
| 答える問い | 誰がここにいて、何をしてよいか？ | このアプリは何で構成されているか？ |
| 場所 | `/_console/apps/setup` | `/_console/studio` |
| ゲート | `setup.access` | `studio.access` |
| 対象 | システム管理者 | 導入担当者と開発者 |

ほとんどの管理作業は Setup から出ることはありません。Studio に入るのは、権限セットを作成するときか、explain エンジンを実行するときだけです。

## Setup アプリ [#the-setup-app]

組み込みの管理アプリは **`/apps/setup`** にあり、`setup.access` 権限が必要です。左側のナビゲーションは、読み込まれている機能プラグインが実行時に提供するので、表示されるメニューはデプロイメントが実行しているものを正確に反映します。無効になっている機能は何も提供せず、そのグループは空のままです。

安定したナビゲーションのグループ：

| グループ | そこにあるもの |
|---|---|
| **Overview** | System Overview ダッシュボード |
| **People & Organization** | Users、Business Units、Teams、Organizations、Invitations |
| **Access Control** | Positions、Permission Sets、Sharing Rules、Record Shares、API Keys |
| **Approvals** | 承認プロセス（承認プラグインが読み込まれている場合） |
| **Configuration** | All Settings、Branding、Authentication、Email、File Storage、AI & Embedder、Knowledge、Feature Flags |
| **Diagnostics** | Sessions、Notification Events、Audit Logs |
| **Integrations** | Webhooks |
| **Advanced** | OAuth Applications、Signing Keys (JWKS)、Identity Links、User Preferences |
