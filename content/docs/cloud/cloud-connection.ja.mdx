セルフホストの ObjectOS サーバー（Community または Enterprise）は、ObjectOS Cloud の組織に接続できます。接続すると、サーバーの **Marketplace** に公開パッケージと並んで組織自身のパッケージが表示され、サーバー自身の認証情報でそれらをインストールします。接続はサーバー側で開始し、クラウド側でワンタイムコードを使って承認します。サーバーに何かを入力する必要はありません。

接続には 2 つの側面があり、このページは両方を扱います。

- **サーバー側**（Community、Enterprise）：接続の開始と切断。前提条件、サーバーが保存するもの、パネルに表示されうるすべてのメッセージを含むサーバー側の完全なリファレンスは、[objectstack.ai の Cloud Connection](https://objectstack.ai/docs/deployment/cloud-connection) にあります。
- **クラウドの組織側**（Cloud）：リクエストの承認と、**Advanced → Connected Runtimes** での接続済みサーバーの管理。

## 接続で得られるもの [#what-connecting-gives-you]

- **サーバーの Marketplace に表示される組織のパッケージ**："Your organization" の下に、[公開](/docs/cloud/apps#publish-an-environment-as-a-package)したプライベートおよび組織のパッケージが表示され、サーバー自身の認証情報で閲覧・インストールされます。
- **組織内の登録**：Connected Runtimes に一覧表示され、サーバーの名前とバージョン、承認したアカウント、接続日時と最終使用日時が示されます。

接続が**不要な**こと：公開マーケットプレイスの閲覧と公開パッケージのインストールは、接続していないサーバーでも動作します。また、コンパイル済みのアーティファクトからのインストールはクラウドを一切呼び出しません。

## 接続する [#connect]

1. **サーバー側で**、**Manage Platform Settings** 権限を持つユーザーとしてサインインし、**Setup → Integrations → Cloud Connection** を開きます。**Connect** を選びます。
2. サーバーはクラウドにワンタイムコードを要求し、新しいウィンドウで承認ページを開きます。コードはサーバーのページにも表示されます。
3. **クラウド側で**、サーバーが参加すべき組織の ObjectOS Cloud アカウントにサインインし、コードが一致することを確認して承認します。
4. サーバーは自動的に完了します。ページが **Connected to ObjectStack Cloud** に変わり、ランタイム、組織、承認したアカウント、日時が表示されます。

時間内に誰も承認しないとコードは期限切れになります。**Connect** からやり直してください。

**承認できる人。** ロールにかかわらず、組織のどのメンバーでも承認できます。サーバーは承認者の**アクティブな**組織に参加します。複数の組織に所属している場合は、承認する前にクラウドコンソールで正しい組織に切り替えてください。

サーバーにはクラウドへのアウトバウンド HTTPS が必要で、作業ディレクトリは永続ストレージでなければなりません。接続はそこにファイルとして保持されます。ObjectOS Cloud 自体がホストするサーバーはプラットフォームによって接続されるため、Cloud Connection ページはありません。

## クラウドで接続済みサーバーを管理する [#manage-connected-servers-in-the-cloud]

クラウドコンソールの **Advanced → Connected Runtimes** には、組織に接続されたすべてのサーバーが、名前、ランタイムのバージョン、承認したアカウント、ステータス、接続日時、最終使用日時とともに一覧表示されます。各行には次の操作があります。

| 操作 | 内容 |
|---|---|
| **Rename** | ここと承認ページに表示される名前を変更します。 |
| **Revoke** | サーバーを即座に切り離します。認証情報が機能しなくなるため、再び承認されるまで、そのサーバー上での組織のパッケージの閲覧、インストール、更新は失敗します。サーバーにすでにインストールされているアプリは動作し続けます。 |
| **Remove** | もう接続されていないサーバー向け：その行を削除します。サーバーはいつでも新しいデバイスとして再接続できます。 |

## サーバーから切断する [#disconnect-from-the-server]

サーバーの **Cloud Connection** ページで **Disconnect** を選びます。サーバーはクラウドに接続の取り消しを依頼し、結果にかかわらず認証情報を削除します。その Marketplace には組織のパッケージが表示されなくなります。

切断しても、次の 2 つは保持されます。

- **インストール済みのすべて。** サーバーにすでにインストールされているパッケージは、インストールされたまま動作し続けます。
- **サーバーのランタイム id。** 再接続すると、新しい行を追加するのではなく、Connected Runtimes の同じ行に紐づきます。

切断時にクラウドに到達できなかった場合でも、サーバーは認証情報を破棄しますが、クラウドには通知されていません。Connected Runtimes を確認し、そこで該当の行を **Revoke** してください。
