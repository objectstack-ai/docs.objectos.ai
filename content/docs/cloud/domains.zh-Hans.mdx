ObjectOS Cloud 上的环境通过一个**平台子域名**访问：即平台域名上一个
由你选择的标签。

| | **平台子域名** |
|---|---|
| 形式 | 平台域名上的 `acme` |
| 套餐 | 所有套餐，包括 Free |
| 数量 | 想加多少就加多少 |
| 证书 | 由平台自己的证书覆盖 |

平台子域名在所有套餐上都免费，依据
[cloud#1087](https://github.com/objectstack-ai/cloud/issues/1087) 的裁定。

ObjectOS Cloud 不提供把你拥有的域名指向环境的功能。

## 修改地址 [#change-the-address]

你的环境的地址是你组织的
[slug](/docs/cloud/organization#the-organization-slug) 加上平台域名。
它在所有套餐上都免费，你选择的任何其他品牌化标签也一样。

要修改它，打开环境的 **Settings → Name and domain**，选择
**Change Hostname**。只需输入标签：平台域名会自动为你加上。
标签由 4 到 63 个小写字母、数字和连字符组成，两端不能是连字符，
也不能有两个连字符相连，少数保留词会被拒绝。它不必
以你组织的 slug 开头。

## 添加第二个地址 [#add-a-second-address]

要添加第二个平台子域名而不是替换第一个，请使用同一部分中的
**Add Domain**。环境 **Overview** 上显示的地址，就是你应该告诉别人的那个。

会话只属于一个地址：在两个地址之间切换，需要重新登录。
