ObjectOS Cloud では、所有するものはすべて**組織**に属します。環境、アプリとパッケージ、プラン、メンバーです。組織はサインアップ時に作成し（[ObjectOS Cloud で始める](/docs/start/cloud)）、[cloud.objectos.ai](https://cloud.objectos.ai) の**クラウドコンソール**で管理します。

## クラウドコンソール [#the-cloud-console]

コンソールのサイドバーが、このセクションの地図です。

| サイドバーの項目 | 中身 | ページ |
|---|---|---|
| **Home** | 組織の概要：本番環境、アプリ、メンバー、今週の AI 利用枠 | — |
| **Environments** | すべての環境と、その設定とライフサイクル | [環境](/docs/cloud/environments) |
| **Members** | 組織の人と、保留中の招待 | このページ |
| **Billing** | プランの比較とアップグレード | [プランと AI シート](/docs/cloud/plans-and-seats) |
| **Advanced → Connected Runtimes** | この組織にリンクされたセルフホストのサーバー | [クラウド接続](/docs/cloud/cloud-connection) |
| **Advanced → Packages** | 組織が公開したパッケージ | [アプリ](/docs/cloud/apps) |

各環境にも、その環境自身のアドレスに独自のコンソールがあります。チームがアプリを使うのはそこで、クラウドコンソールはそれらを取り巻く組織を管理する場所です。

## 組織のスラッグ [#the-organization-slug]

**スラッグ**は組織の短い識別子で、サインアップ時に選びます。本番環境のアドレスでもあり、スラッグの後にプラットフォームのドメインが続きます。

- 4〜30 文字：小文字、数字、ダッシュ。
- 先頭と末尾にダッシュは使えず、ダッシュを 2 つ続けることもできません。
- 予約語の短いリストは拒否されます（`admin`、`api`、`www`、`docs`、`default` など、プラットフォーム自身が使うもの）。

オーナーまたは管理者は、組織のレコードの **Change Slug** でスラッグを変更できます。変更は 90 日に 1 回までです。組織のすべてのプラットフォームのサブドメインが新しいスラッグに書き換えられ、古いスラッグは 90 日間保持されるので、その間にほかの誰かがそれを取ることはできません。独自のドメイン（[ドメイン](/docs/cloud/domains)）はスラッグの変更の影響を受けません。

## メンバーと招待 [#members-and-invitations]

サイドバーで **Members** を開きます。このページには 2 つのタブがあります。ロール付きのメンバーと、まだ保留中の招待です。

誰かを追加するには、**Invite members** を選び、メールアドレスを入力してロールを選びます。相手は招待を受け取り、それを承諾すると組織のメンバーになります。

**組織の招待が、その環境に入る唯一の方法です。** 環境には独自の招待もセルフサインアップもありません。ここで招待した全員が組織の環境に入ることができ、環境の中で何ができるかは、その環境の[権限](/docs/configure/permissions)が決めます。

リストから、組織を管理する人は**メンバーのロールを変更**、**メンバーを削除**、保留中の招待を**再送**または**取り消し**できます。

## ロール [#roles]

メンバーシップのロールは、人が組織の中で何に届くかを決めます。これは権限セットではありません。環境の中でレコードに対して何ができるかは、その環境の[権限セットとポジション](/docs/configure/permissions)から来ます。

| ロール | 用途 | 招待できる人 |
|---|---|---|
| **Owner** | 組織、そのプラン、その環境の完全な管理 | オーナー |
| **Admin** | 組織を管理します：メンバー、環境、請求 | オーナーまたは管理者 |
| **Delegated Admin** | 管理者でなくても招待のエンドポイントに届きます。人をどこに配置できるかは、別に付与される管理のスコープから来ます | オーナーまたは管理者 |
| **Member** | 組織の環境とアプリを使います | 招待できる人なら誰でも |
| **External** | ポータルのユーザー（仕入先や顧客）で、自分の行と明示的に共有されたものだけを見ます。事業単位のツリーには決して含まれません | 招待できる人なら誰でも |

このセクションで「組織を管理する人」と言うのは、オーナーと管理者のことです。彼らには、プラン、アップグレード、何かを変更する環境のアクションが表示されます。一般のメンバーは環境を見て開けますが、完了できないアクションは提示されません。

## サインインのある場所 [#where-sign-in-lives]

ObjectOS Cloud では、すべてのアカウントがクラウドのアカウントです。ObjectOS Cloud が人をサインインさせ、環境がその人を受け入れます。環境が各人について保持するのは**認可だけ**、つまりポジション、権限セット、共有です。すべてのホスト型の環境は、どのプランでもデフォルトでこの単一のサインインを使うので、人は ObjectOS Cloud のアカウントで一度サインインし、環境の間を移動できます。

**環境を自社のインフラストラクチャに移す場合。** アカウントは環境ではなく ObjectOS Cloud にあるので、環境とともに移動はしません。セルフマネージドのデプロイメントでは、そこで人に新しい認証情報を発行するか、自社のアイデンティティプロバイダーにバインドしてそれを通じてサインインさせます。[認証](/docs/configure/authentication)を参照してください。
