ObjectOS Cloud の環境は、**プラットフォームのサブドメイン**で応答します。プラットフォームのドメイン上の、自分で選んだラベルです。

| | **プラットフォームのサブドメイン** |
|---|---|
| 見た目 | プラットフォームのドメイン上の `acme` |
| プラン | Free を含むすべてのプラン |
| 数 | いくつでも追加できます |
| 証明書 | プラットフォーム自身のものでカバーされます |

[cloud#1087](https://github.com/objectstack-ai/cloud/issues/1087) の決定により、プラットフォームのサブドメインはすべてのプランで無料です。

ObjectOS Cloud では、所有するドメインを環境に向けることはできません。

## アドレスを変更する [#change-the-address]

環境のアドレスは、プラットフォームのドメイン上の組織の[スラッグ](/docs/cloud/organization#the-organization-slug)です。これはすべてのプランで無料で、自分で選ぶほかのブランド付きのラベルも同じく無料です。

変更するには、環境の **Settings → Name and domain** を開き、**Change Hostname** を選びます。ラベルだけを入力します。プラットフォームのドメインは自動で付きます。ラベルは 4〜63 文字の小文字、数字、ダッシュで、両端にダッシュは使えず、2 つ続けることもできません。いくつかの予約語は拒否されます。組織のスラッグで始まる必要はありません。

## 2 つ目のアドレスを追加する [#add-a-second-address]

最初のものを置き換えるのではなく 2 つ目のプラットフォームのサブドメインを追加するには、同じセクションの **Add Domain** を使います。環境の **Overview** に表示されるアドレスが、人に伝えるべきアドレスです。

セッションは 1 つのアドレスに属します。2 つのアドレスを切り替えると、もう一度サインインすることになります。
